# 💚 Conheça o CATHEU

[⬅️ Apresentação](../README.md) · [✨ Abrir demo](https://msbraga47.github.io/catheu-demo/)

## Clareza antes de complexidade

A experiência deve ser compreensível para quem está começando a organizar as finanças. O panorama destaca receitas, despesas e resultado. As categorias explicam para onde o dinheiro foi; clicar ou tocar aproxima o gráfico dos lançamentos.

## Uma amostra para explorar

A demo tem dois meses fictícios, movimentações simples e filtros. Criar, editar ou excluir um exemplo altera os totais imediatamente. Restaurar substitui as alterações pelos exemplos iniciais, após confirmação.

Todas as movimentações desta amostra são tratadas como pagas. Ela não simula contas bancárias, transferências, parcelas, vencimentos ou pagamento de faturas. A data fica limitada aos dois meses demonstrados. As alterações são temporárias e limitadas a esta aba, com até 100 exemplos.

## O projeto completo

O CATHEU completo busca conectar contas, transferências, importação de extratos, cartões, faturas, pendências, metas, investimentos e relatórios. A demonstração não contém esse motor financeiro nem tem acesso a dados reais.

As áreas além do escopo exibem uma tela de contato. Não é preciso cadastrar-se nem enviar informações para navegar pelos exemplos.
